[venv]

- SHAP 기반 해석과 정보이론적 앙상블 흐름은 지금 구조로 충분합니다. 중복 페널티( CMI·VIF·상관계수 ), 비용 민감 NLL을 GA 적합도에 넣었고, 최종 평가는 비용 민감 지표와 페널티/규모 항을 모두 반영하도록 `Module` 하위에서 모듈화했습니다. 필요하면 SHAP을 옵션(`--skip-explainability`)으로 껐다 켤 수 있어요.

- 요청하신 가상환경 세팅 스크립트와 의존성 목록을 추가했습니다.  
  - `requirements.txt` : numpy, pandas, scikit-learn, scipy, imbalanced-learn, shap  
  - PowerShell 스크립트 `scripts/setup_env.ps1` : `.venv` 생성/재생성, pip 업그레이드, 의존성 설치까지 자동화합니다.

### 가상환경 사용 예시
```
powershell -ExecutionPolicy Bypass -File scripts/setup_env.ps1 -Recreate
.\.venv\Scripts\Activate.ps1
python main.py --data-path ..\Data\creditcard\creditcard.csv
```
(필요 시 `--skip-explainability`, `--weight-*`, `--lambda-penalty` 등 인자 조절)

설정 후 `.\.venv\Scripts\Activate.ps1`만 실행하면 언제든 환경을 재사용할 수 있습니다.

### 실행 방법

1. (선택) 가상환경 생성·의존성 설치  
   ```
   powershell -ExecutionPolicy Bypass -File scripts/setup_env.ps1
   .\.venv\Scripts\Activate.ps1
   ```
   혹은 기존 환경을 재사용하면 `.venv` 활성화만 하시면 됩니다.

2. 파이프라인 실행  
   ```
   python main.py --data-path ..\Data\creditcard\creditcard.csv
   ```
   기본은 scikit-learn 로지스틱을 사용합니다.

3. 커스텀 솔버를 쓰려면 예를 들어:
   ```
   python main.py --data-path ..\Data\creditcard\creditcard.csv ^
                  --use-solver ^
                  --solver-method adam ^
                  --solver-line-search ^
                  --solver-second-order none
   ```
   - `--solver-method {gd, momentum, nesterov, adam}`
   - `--solver-line-search` 켜면 백트래킹 라인 서치 사용
   - `--solver-second-order bfgs`로 주면 준-뉴턴(BFGS) 사용
   - 필요하면 `--solver-lr`, `--solver-max-iter`, `--solver-momentum` 등도 조정하세요.

실행 후 콘솔에 GA 진행 로그, 솔버 수렴 정보, 평가 결과(ROC-AUC, PR-AUC, cost-sensitive 리포트 등)가 출력됩니다.

- `main.py`는 이제 기본적으로 커스텀 솔버를 사용합니다. 별도 옵션을 주지 않으면 `SolverConfig`와 `gradient_descent_cost_sensitive/bfgs_cost_sensitive` 경로가 실행됩니다.  
  다른 백엔드가 필요하면 `--solver-backend sklearn`을 명령행에 지정하세요.

- 6장(헤시안/준-뉴턴) 기능은 `--solver-second-order` 인자로 제어합니다.  
  - 기본값 `none`: 1차(Gradient/Momentum/Nesterov/Adam) 기반  
  - `--solver-second-order bfgs`: BFGS 근사 헤시안으로 업데이트  

  나머지 1~5장 기법(라인 서치, 모멘텀, Adam 등)은 `--solver-method`, `--solver-line-search` 등의 정보로 구성되어 있어 상황에 따라 조합할 수 있습니다.

즉, 실행 기본은 커스텀 솔버이며, 필요 시 `--solver-backend sklearn`으로 scikit-learn 로지스틱으로 전환하고, 6장 내용을 적용하려면 `--solver-second-order bfgs`를 덧붙이면 됩니다.
